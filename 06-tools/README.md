# Инструменты сборки

Как получить .docx для редактора из размеченной страницы статьи.

```bash
python3 razmetka-v-json.py <статья>.html blocks.json
node json-v-docx.js blocks.json <имя>.docx "Заголовок"
```

`razmetka-v-json.py` читает нашу разметку страницы: блоки `.blk` с классом
`keep` / `tz` / `fact` / `lang`, примечания `.note`, источники `.src`,
вопросы заказчику `.ask`, заголовки, списки и таблицы.

`json-v-docx.js` собирает .docx: заливка по типу блока, метка в начале группы,
легенда в начале документа, источники серым курсивом, вопросы заказчику красным.
Жирный текст размечается `**` — парсер переносит его из `<b>`.

Так документ и страница собираются из одного источника и не расходятся.
Конвертировать HTML в .docx через LibreOffice нельзя: заливки теряются,
а кнопки фильтра попадают в текст.
