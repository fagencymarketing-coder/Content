# Контент 1+1

База проекта: статьи и посты для сайта и Telegram бухгалтерской компании «1+1».

**Начинать с `00-instruction/INSTRUCTION.md`** — главный документ, построен вокруг
четырёх задач: интересно, точно, по-русски, SEO и размещение.

## Структура

```
00-instruction/
  INSTRUCTION.md            главная инструкция
  AUDIT.md                  разбор: почему статьи не проходили проверку и что изменено

01-standards/
  tochnost.md               экспертная точность и фактура          → задача 2
  yazyk.md                  стандарт языка, семь типов ошибки      → задача 3
  kak-nado.md               глаголы, уровни надёжности, образцы    → справочник к 2 и 3
  pary-do-posle.md          журнал правок «было → стало»

02-knowledge-base/
  kompaniya.md              факты о компании, запретные имена
  celevaya-auditoriya.md    сегменты, боли из CustDev              → задача 1
  keysy.md                  реальные кейсы с цифрами
  formaty.md                пять форматов, статья и пост, эмодзи

03-seo/
  seo.md                    от ТЗ до размещения: ТОП, ключи, памятка → задача 4

04-references/
  accepted/                 тексты, прошедшие проверку
  rejected/                 отклонённые тексты с правками редакторов
  old-project/              архив базы знаний старого проекта
  brief-vk.*                бриф на рекламную кампанию

05-content/
  articles/                 готовые статьи для сайта
  telegram/                 готовые посты
```

## Чего не хватает

- Файл ключевых запросов с частотностью.
- Кейсы 2025–2026 годов.
- Наблюдения из практики: частые ошибки клиентов, реальные сроки процедур,
  где придирается налоговая.
