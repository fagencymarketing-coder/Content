# Контент 1+1

Рабочая база проекта: бухгалтерский аутсорсинг «1+1» (Барнаул/Алтайский край + удалённые клиенты по России).
Контент для сайта и Telegram. Цель: лиды + экспертный авторитет.

## Структура

| Папка | Что внутри |
|---|---|
| `00-instruction/` | Главный документ — правила работы над контентом |
| `01-standards/` | Стандарты языка, эталоны тона, образцы подачи |
| `02-knowledge-base/` | Факты о компании, ЦА, CustDev, база кейсов |
| `03-seo/` | Кластеры запросов, требования к разметке |
| `04-references/` | Примеры текстов: свои (2020–2022, 2026), ориентиры |
| `05-content/` | Готовые тексты: `articles/` — сайт, `telegram/` — посты |

## Статус

Проект пересобирается. Инструкция предыдущего проекта сохранена как базовая версия
(`00-instruction/CUSTOM-INSTRUCTIONS.md`) — она пересматривается, потому что качество
статей в прошлом проекте не устроило заказчика.

Разбор слабых мест и план переработки — `00-instruction/AUDIT.md`.
