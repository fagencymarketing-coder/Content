# Проверка презентации v1

15 слайдов. Проверено: соответствие заданию, перенос текста из документа, вёрстка.

## Задание выполнено

| Пункт задания | Как сделано |
|---|---|
| Структура из 12 пунктов | Развёрнута в 15 слайдов: «Предмет гранта», «Сравнение» и «Перспективы» разбиты на два слайда каждый — верно, так читается легче |
| Деловой сдержанный стиль | Светлый фон, тёмный текст, оливковый для надзаголовков, малиновый точечно. Без градиентов, теней, стоковых фото |
| Фирменные цвета | Оливковый и малиновый из гайдбука |
| Формат, колонтитул, нумерация | 16:9, на каждом слайде «ИИ-помощник Бухдеск · ООО «1+1 Бухдеск»» и номер |
| Эмодзи ✅ заменить | Заменены на квадратные маркеры |
| Схема сценария | Четыре шага со стрелками, текст со слайда не продублирован |
| Таблица сравнения | Перенесена без ошибок, столбец «Бухдеск» выделен малиновым |
| Заполнители | Название, сумма, срок, снимок экрана, 5 источников, бюджет, команда, логотипы — все отмечены пунктиром |
| Не добавлять фактов | Соблюдено, с одной оговоркой (ниже) |

Таблицу сравнения сверил по ячейкам с исходным документом — все 24 значения совпадают.

## Что требует решения

### 1. Добавлена строка, которой нет в документе

Слайд 9, под заголовком: «Модели распознавания и генерации — российские: SpeechKit
и YandexGPT». В исходном тексте этой фразы нет — она собрана из пункта про
распознавание и из слайда о перспективах.

По сути верно и для грантовой экспертизы полезно. Но решение добавить текст
принимает заказчик, а не исполнитель. Оставить или убрать — на ваше усмотрение.

### 2. Ошибки текста перенесены как есть

Это было в задании: текст не менять. Поэтому в презентации остались все места
из примечаний к документу. Перед подачей править нужно в тексте, потом
пересобрать слайды:

| Слайд | Что исправить |
|---|---|
| 2 | «Клиент имеет Доступ» — заглавная буква в середине предложения |
| 8 | «предпринимателя, самостоятельно, выставляющего» — лишние запятые |
| 8 | «НЕОПЕРАТИВНОЕ» прописными — в вёрстке выглядит резко, слово попало в заголовок |
| 9 | «Вебинтерфейс» → «Веб-интерфейс», «отсутсвие» → «отсутствие» |
| 10 | «На рынке нет подобного сервиса» — противоречит таблице под этой же фразой |
| 10 | ИИ-агент у «Бухдеска» — «Да», хотя функция создаётся за счёт гранта |
| 11 | Незакрытые скобки: «(Entera, …), ARQA)» |
| 15 | «400+ клиентов» — по вашим данным 450; «РАЕКС» → RAEX |

### 3. Мелкое по вёрстке

- **Слайд 3.** В плитке «71 тыс. руб.» число и единица набраны разным кеглем,
  а в соседних плитках единица входит в число. Выровнять.
- **Слайд 8.** Пять плиток в ряд при разной длине подписей дают рваный низ.
  Заполнители «Источник: заполнить» это скрывают, но после заполнения стоит
  проверить ещё раз.
- **Слайд 10.** Под последней строкой таблицы осталась пустая строка — похоже
  на обрезанную шестую строку. Убрать.
- **Слайд 1.** «БУХДЕСК» в заголовке и «БУХДЕСК» в подзаголовке — повтор виден
  сильнее, чем в документе.

## Чего по-прежнему нет для заявки

Напоминание из примечаний к тексту — вёрстка это не решает:
запрашиваемая сумма, срок, план-график по этапам, измеримые показатели результата,
риски, софинансирование.
