# Страница «Абонентское бухгалтерское обслуживание»

Страница: https://1-plus-1.ru/bukhgalterskie-uslugi/abonentskoe-obsluzhivanie/
Рекомендации: `03-seo/rekomendacii/rekomendacii-10.11.md`, девять пунктов.

| Рекомендация | Что сделано |
|---|---|
| Проработать H1 | Предложен вариант с услугой, городом и ценой; разбор — в служебном блоке |
| Текстовый блок H2 | «Что входит в абонентское обслуживание и как это защищает ваш бизнес» |
| Раскрыть состав | «Из чего складывается абонентское обслуживание»: четыре участка, у каждого «если этого не делать» с нормой |
| Блок «Как мы работаем» | «Прозрачность на каждом этапе» — путь клиента из пяти шагов таблицей; заменяет нынешний блок |
| Раскрыть тарифы | «Выберите тариф под задачи вашего бизнеса»: таблица из четырёх факторов цены |
| FAQ | «Частые вопросы об абонентском обслуживании», семь вопросов |
| Отраслевая специфика | «Мы работаем со всеми видами деятельности», отрасли по реальным кейсам |
| Покрытие запросов про аутсорсинг | Закрыто вводным текстовым блоком и блоком состава |
| Блок «Другие услуги» | Четыре ссылки на страницы услуг с подтверждёнными адресами |

## Сделано строго по рекомендациям

Приведено к букве 21.11.2026: H1 — только три варианта из рекомендации,
без своего; тарифы — четыре фактора цены списком, как в тексте рекомендации;
FAQ — четыре вопроса вместо семи; отрасли — второй из двух предложенных
вариантов, без списка ниш; призыв к действию снят.

Чего нет, хотя рекомендация просит: таблицы сравнения тарифов — нет данных,
чем УСН 6%, УСН 15% и ОСНО различаются по составу работ.

## Главное наблюдение

Блок «Как мы работаем?» на странице описывает не работу, а состав услуги:
под этим заголовком перечень «оформляем первичку, начисляем зарплату,
считаем налоги». Процесса на странице нет вообще, и клиент не знает, что
будет после заявки. Поэтому блок заменяется, а перечень переезжает в состав.

## Что требует подтверждения

Путь клиента, ответы на требования в тарифе, частичное обслуживание и
поведение при опоздании с документами — в тексте помечены вопросами.
Эти детали взяты из рекомендации, а не из нашей практики.
